## ✨ Новые функции

### 📄 Экспорт скрипта перевода в DOCX / TSV / TXT (R10-И4)
*Закрывает запрос: Надежда#5*

В разделе **Файлы** рабочего пространства появились кнопки экспорта скрипта перевода в трёх форматах:
- **DOCX** — документ Microsoft Word с цветовым форматированием (таймкод синим, оригинал серым)
- **TSV** — таблица для Google Sheets / Excel (таймкод | оригинал | перевод)
- **TXT** — текстовый файл с таймкодами для диктора

Реализовано без внешних зависимостей (нативный Python zipfile + OpenXML).

### 📦 Batch загрузка нескольких файлов (R10-И3)
*Закрывает запрос: Дмитрий#2*

Drag-and-drop зона теперь принимает несколько видеофайлов одновременно:
- Поддержка до N файлов за раз
- Очередь загрузки с индикатором прогресса (⏳ → 🔄 → ✅ / ❌)
- Кнопка "Открыть" для мгновенного перехода к созданному проекту

### 📚 Глоссарий терминов доступен всем (R10-И2)
*Закрывает запросы: Дмитрий#4, Андрей#10*

Секция "Глоссарий" в Расширенных настройках теперь видна всем пользователям, а не только в Professional режиме.

### 💰 Стоимость запуска в карточке проекта (R10-И5)
*Закрывает запрос: Виктор#4*

В карточках проектов на Dashboard теперь показывается суммарная стоимость последнего запуска (из billing_snapshots). Наводите мышкой для детализации по этапам.

### 🚨 Улучшенный UX ошибок загрузки (R10-И1)
*Закрывает запросы: Надежда#1, Надежда#2, Надежда#8*

- Ошибки загрузки файлов показывают конкретное описание проблемы
- Формат файла, размер, сеть — каждый случай имеет понятное сообщение
- Добавлен retry-механизм с кнопкой "Попробовать снова"
