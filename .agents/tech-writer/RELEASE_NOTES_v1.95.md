## v1.95.4 — Оценка качества перевода (Quality Thresholds)

- **[Новое]** Индикатор «🎯 Оценка качества» во вкладке Статистика — число 0–100 с расшифровкой (Отлично / Хорошо / Удовлетворительно / Плохо)

## v1.95.0 — Автоматические повторы при сбоях (Retry/Backoff)

### Для пользователей 🎉
- **[Улучшено]** При временных сбоях сети или провайдера система **автоматически повторяет** запрос до 3 раз
- **[Улучшено]** Нарастающие паузы между попытками: 2с → 4с → 8с — меньше потерянных переводов
- **[Улучшено]** Ошибки 4xx (кроме 429) не повторяются — нет лишних запросов при невалидных данных
- **[Улучшено]** Ошибка 429 (лимит) — минимальная пауза 5с перед повтором

### Для разработчиков 🔧
- `with_retry(fn, retries=3, base_sleep=2.0, non_retryable_4xx=True)` — декоратор в `utils/retry.py`
- Покрыты: SpeechKit TTS (`_synth`, `_synth_plain`), Cloud translator (`_post_json`, `_attempt`), Webhook (`_send_sync`)
- 12 тестов в `tests/test_retry.py`

### Исправления 🐛
- Нет критических исправлений
