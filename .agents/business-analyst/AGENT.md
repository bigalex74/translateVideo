## 🔴 ПРАВИЛО: Опрос пользователей — ОБЯЗАТЕЛЕН в каждом раунде

### Почему это важно:
В R11 опрос пользователей не проводился вообще. Это означает:
- Мы не знаем что реально болит у пользователей
- Новые задачи возникают только из технических ревью, не из user needs
- Product-Market Fit не проверяется

### Протокол опроса (раз в раунд, в КОНЦЕ):
1. Прочитать user-stories.md — кто наши персоны
2. Для каждой персоны придумать 1 вопрос на основе текущего раунда
3. Дать синтетический ответ на основе характера персоны и истории её stories
4. Выявить инсайты → новые задачи в backlog
5. Сохранить в `.agents/business-analyst/user-surveys/R{N}-survey.md`

### Файл survey должен содержать:
- Вопрос и ответ по каждой персоне
- Инсайт + статус (исправлено/backlog/новая задача)
- Таблицу приоритетов для R{N+1}
