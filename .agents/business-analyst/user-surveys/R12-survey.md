**Устройство:** Ubuntu + VSCode + curl  
**Техграмотность:** 9/10 (высокая)  

**10 замечаний:**

1. 🔴 **КРИТИЧНО:** Polling каждые 2 секунды — это варварство. WebSocket обязателен для API-клиентов.
2. 🔴 **КРИТИЧНО:** Нет webhook support — я не могу получить callback когда готово. Должен держать соединение открытым.
3. 🔴 **КРИТИЧНО:** API возвращает `null` для `progress` пока не стартовал пайплайн — нужно чёткое состояние `queued/running/done/failed`.
4. 🟡 **МАЖОР:** Нет SDK / клиентской библиотеки (Python, JS) — пишу wrapper вручную.
5. 🟡 **МАЖОР:** `dynamic import` в client.ts предупреждение в консоли при каждом запросе — это шум в логах.
6. 🟡 **МАЖОР:** Batch endpoint существует но нет нормальной документации — нашёл только через исходники.
7. 🟢 **МИНОР:** Rate limiting не задокументирован — сколько запросов в минуту?
8. 🟢 **МИНОР:** OpenAPI spec устарел — не совпадает с реальным API в нескольких местах.
9. 🟢 **МИНОР:** Health endpoint возвращает только версию — хочу статус очереди и нагрузку.
10. 🟢 **МИНОР:** CORS настроен на `*` — в production так нельзя.

**Ключевые инсайты → P1:**
- WebSocket (Г7 — уже в бэклоге, подтверждение)
- Webhook/callback support (WEBHOOK — НОВЫЙ)
- dynamic import fix (QA-001 — уже в бэклоге)
